## Nexora

**Nexora** is a technology company focused on building a connected ecosystem of software products designed around one principle:

> **Technology should feel simple.**

### Products

* **NCode** — Modern code editor for Linux and Android.
* **NPhotos** — Private and intuitive photo management.
* **Nexora Web** — The digital platform and public home of Nexora.
* **More in development.**

---

## What we're building

Nexora is not a single product.

It is an ecosystem.

Our goal is to create software where individual products work beautifully on their own while becoming more valuable as part of the larger Nexora experience.

**Simple by design.
Powerful by default.
Built to last.**
